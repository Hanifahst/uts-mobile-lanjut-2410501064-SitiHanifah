## Cara Install & Menjalankan

1. Clone terlebih dahulu di terminal

   ```bash
   git clone https://github.com/Hanifahst uts-mobile-lanjut-2410501064-SitiHanifah 
   ```

2. Masuk ke dalam folder

   ```bash
   cd movie_dex
   ```
3. npm Install

   ```bash
   npm install
   ```

4. Start expo

   ```bash
   npx expo start
   ```
